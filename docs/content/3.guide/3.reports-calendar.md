## Reports

The Reports page aggregates the whole org's entries over a date range. All aggregation happens server-side in one SQL pass (chains and rates resolve per [Rules 1–2](/guide/projects-clients-tasks)); trashed rows and the running timer are always excluded.

### Filters

- **Range**: *This week / Last week / This month*, plus a **custom range** with explicit from/to dates. The header subline restates the resolved range ("This week · Sep 7 – Sep 13 · 24 entries").
- **Billable**: *All / Billable / Non-billable*.
- **Group by**: *Client / Project / Task / Tag* — regroups both the chart and the breakdown table.

### What you see

- **Stat cards**: Tracked (with worked-day count), Billable (% of tracked), Amount (with average $/h), Per day (average over worked days).
- **Hours by day**: a stacked column chart, one column per day, segments colored by the current grouping. Series colors are assigned by rank on the server and shared between the chart and the table chips, so the legend always matches.
- **Breakdown table**: color chip + label + parent sub-line, a share bar with %, entry count, hours, billable hours and amount, with a Total row. Unassigned time is real data, not hidden — "No client", "No project", "No task" and "Untagged" appear as their own rows.

Grouping by tag counts an entry once **per tag** in the rows; the totals row still counts each entry once.

### Export

- **CSV** downloads the range through `GET /api/export/csv` (respects the billable filter). Columns: `date, start, end, duration_h, name, task, project, client, tags, billable, rate, amount` — RFC 4180 quoting, ready for a spreadsheet.
- **Print / PDF** uses the browser's print dialog with a print-friendly layout, so "Save as PDF" produces a clean report.

## Calendar

The Calendar shows entries as blocks on a time grid — **Week** (7 columns, Monday start) or **Day** view, with ‹ **Today** › navigation. The base window is 7am–7pm; days with earlier or later entries extend the grid, and the body scrolls when it outgrows 12 hours. Each day header shows the weekday, the day number (accent ring on today) and that day's total; today gets a live "now" line.

Blocks carry the entry name and chain, with an accent edge when billable. The **running timer** renders as a live block growing toward now — it is display-only until you stop it.

### Editing by drag

Everything snaps to **5 minutes**, and `Esc` cancels an in-progress drag:

| Gesture | Effect |
| --- | --- |
| Drag on empty space | Draws a ghost block, then opens the manual-entry dialog prefilled with that day and time range |
| Drag a block | Moves it — across days too, in week view |
| Drag a block's top/bottom edge | Resizes it (changes start or end) |
| Click a block (no drag) | **Start again** — copies name, reference and billable flag to the timer and starts it |

Moves and resizes commit optimistically and revert if the server rejects them; duration and amount always come back from the server, so rate resolution stays correct after an edit.
