All routes live under `/api`, speak JSON, validate bodies and queries with zod, and require a session cookie — except `/api/auth/*` and the public invite lookup. Auth uses [nuxt-auth-utils](https://github.com/atinux/nuxt-auth-utils) sealed session cookies; log in once with `POST /api/auth/login` and reuse the cookie.

Multi-user scoping: catalog and reporting routes operate on the whole **org**; the timer and entry mutations operate on the **current user**.

## Auth

| Method | Route | Description |
| --- | --- | --- |
| POST | `/api/auth/register` | `{name, email, password}` → creates user + personal org (role owner), sets session. Accepts an invite token to join an existing org instead |
| POST | `/api/auth/login` | `{email, password}` → sets session |
| POST | `/api/auth/logout` | Clears the session |

## Current user

| Method | Route | Description |
| --- | --- | --- |
| GET | `/api/me` | Fresh `SessionUser` + saved theme |
| PATCH | `/api/me/profile` | `{name?, email?, defaultRate?}` — 409 on duplicate email |
| PATCH | `/api/me/password` | Change password (current password required) |
| PATCH | `/api/me/theme` | Persist the theme editor's settings (jsonb) |

## Timer

| Method | Route | Description |
| --- | --- | --- |
| GET | `/api/timer` | `TimerState` or `null` |
| POST | `/api/timer/start` | `{name?, refType?, refId?, billable?}` → `TimerState`; **409 if one is already running** |
| PATCH | `/api/timer` | Edit the running timer (name, reference, billable) |
| POST | `/api/timer/stop` | → `EntryDto`, or `null` when under 1 second (discarded) |

## Entries

| Method | Route | Description |
| --- | --- | --- |
| GET | `/api/entries?from&to` | `EntryDto[]` in `[from, to)`, newest first; excludes running + trashed |
| POST | `/api/entries` | Manual entry: `{name, refType?, refId?, billable?, rateOverride?, start, end, tags?}` |
| PATCH | `/api/entries/:id` | Partial update, same fields |
| DELETE | `/api/entries/:id` | Soft delete → `DeleteResult` |
| POST | `/api/entries/bulk` | `{ids, action: 'delete' \| 'billable' \| 'restore' \| 'reassign', billable?, refType?, refId?}` — reassign moves entries to a new deepest reference (null clears) |

## Catalog

Clients, projects, tasks and tags share the same CRUD shape. Cascade endpoints return the counts the [cascade dialog](/guide/projects-clients-tasks#rule-3-cascade-delete) shows.

| Method | Route | Description |
| --- | --- | --- |
| GET / POST | `/api/clients` | List `ClientDto[]` / create `{name, rate?}` |
| PATCH / DELETE | `/api/clients/:id` | Update / cascade delete (body `{cascadeProjects, cascadeTasks, cascadeEntries}`) → `DeleteResult` |
| GET | `/api/clients/:id/cascade` | `CascadeCounts` for the dialog |
| GET / POST | `/api/projects` | List `ProjectDto[]` / create |
| PATCH / DELETE | `/api/projects/:id` | Update / cascade delete (body `{cascadeTasks, cascadeEntries}`) |
| GET | `/api/projects/:id/cascade` | `CascadeCounts` |
| GET / POST | `/api/tasks` | List `TaskDto[]` / create |
| PATCH / DELETE | `/api/tasks/:id` | Update / delete |
| GET / POST | `/api/tags` | List `TagDto[]` / create (lowercased, deduped) |
| DELETE | `/api/tags/:id` | Strips labels from entries; never touches time |
| POST | `/api/restore` | `{deleted}` from any `DeleteResult` → undo, restores the exact snapshot |

## Summaries & export

| Method | Route | Description |
| --- | --- | --- |
| GET | `/api/summary/dashboard` | `DashboardSummary` — today/week stats, 16-week activity, week bars, billable % |
| GET | `/api/summary/reports?from&to&billable&groupBy` | `ReportSummary` — stacked days, regroupable breakdown, totals |
| GET | `/api/export/csv?from&to&billable` | The range as a `text/csv` attachment (`date, start, end, duration_h, name, task, project, client, tags, billable, rate, amount`) |

## Import

| Method | Route | Description |
| --- | --- | --- |
| POST | `/api/import/preview` | `{source: 'toggl' \| 'clockify' \| 'generic', csv}` → `ImportPreview` (dry run, writes nothing) |
| POST | `/api/import/commit` | Same body → `ImportCommitResult` (creates catalog rows + inserts entries) |

## Organization & team

| Method | Route | Description |
| --- | --- | --- |
| GET / PATCH | `/api/org` | Org info / rename (owner/admin) |
| GET | `/api/org/members` | `OrgMemberDto[]` |
| PATCH | `/api/org/members/:userId` | Change role or rate override (owner/admin; last owner protected, 409) |
| DELETE | `/api/org/members/:userId` | Remove member (owner/admin; last owner protected) |
| GET / POST | `/api/invites` | List pending / create `{email, role}` → invite with copyable token (7-day expiry) |
| DELETE | `/api/invites/:id` | Revoke an invite |
| GET | `/api/invites/lookup/:token` | **Public** — email/role/org for the register page; 404 unknown, 410 expired or used |

## Trash

| Method | Route | Description |
| --- | --- | --- |
| GET | `/api/trash` | `TrashDto` — trashed rows per entity with days-left; auto-purges anything older than 30 days first |
| POST | `/api/trash/purge` | `{all: true}` or `{items: {entity: ids[]}}` — hard delete ("Delete forever") |
