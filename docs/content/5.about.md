## Inspiration

Tick began as an answer to [SolidTime](https://github.com/solidtime-io/solidtime), the open-source time tracker for freelancers and agencies. SolidTime's shape — sidebar, ever-present timer, entries list — is great; Tick keeps that shape and reworks the parts its author wanted done differently:

- A more **open-ended data model**: projects don't need clients, tasks don't need projects, and an entry can attach to any level (or none) with derived-not-copied chains.
- **Safer deletion**: cascade previews that spell out consequences, soft delete everywhere, a 30-day trash, and exact undo.
- **Typed dates**: free-text date/time/duration parsing in manual entry instead of pickers.
- A real **theme editor** rather than a fixed skin.

## Built with

- [Nuxt](https://nuxt.com) 4 — app framework (and [Nuxt Content](https://content.nuxt.com) for this documentation)
- [Nuxt UI](https://ui.nuxt.com) 4 + [Tailwind CSS](https://tailwindcss.com) 4 — components and theming
- [Pinia](https://pinia.vuejs.org) — client state
- [Drizzle ORM](https://orm.drizzle.team) + [postgres.js](https://github.com/porsager/postgres) — PostgreSQL access and migrations
- [nuxt-auth-utils](https://github.com/atinux/nuxt-auth-utils) — sealed-cookie sessions (passwords hashed with Node's scrypt)
- [GSAP](https://gsap.com) — chart draw-ins and motion
- [Zod](https://zod.dev) — API validation
- [Lucide](https://lucide.dev) icons · [Inter](https://rsms.me/inter/) and friends via Google Fonts

## Contributing

The repository ships everything the app needs: schema, migrations, seed data, a Docker image and a design handoff (`handoff_design_Tick/`) documenting the visual system and data rules. Start with the [data model](/reference/data-model) and [API reference](/reference/api).
